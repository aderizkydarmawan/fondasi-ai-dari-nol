# Fondasi AI dari Nol

Situs belajar matematika, statistika, dan fisika di balik AI, mulai dari nol, dalam bahasa Indonesia.

- Setiap pelajaran berisi penjelasan, contoh soal, visualisasi interaktif ("Coba sendiri"), bagian "Lebih dalam", kesalahan umum, ringkasan, dan tes kertas kosong.
- Kode Python bisa dijalankan langsung di browser (Pyodide). Semua output sudah dicek dengan Python lokal.
- Setiap pelajaran mencantumkan sumber (buku, bab, halaman).

Situs statis tanpa build: `index.html`, `kurikulum.js`, `lapis*.js` (isi pelajaran), `dalam.js` (pendalaman), `viz.js` (visualisasi).
Jalankan lokal: `python -m http.server`.
